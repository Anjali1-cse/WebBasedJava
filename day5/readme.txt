JSP stand for jakarta server pages.
JSP is web component that is used to extend the functionality of webserver.
it is a component that run on server side.
it can be used to generate dynamic web pages.

life Cycle of JSP
like servlet,JSP life cycle consists of stages

1. Instatiation and Intalization
2. Service
3. Destroy
to handle  the life cycle there 3 methods inuse which are referred as life cycle 
method
1.jspInit()
2.jspService()
3.jspDestroy()

- when the JSP is requested for the 1st time, it is loaded by Web container.
- As soon as the loading is finished , it iscompiled and translated or coverted into 
servletis generated by web container itself and this class povides implementation
of life cycle methods .
- futher the container instantiates this classs and invokes jspInit() method. 
 - then it invoke _jspService() method.
 - when thw JSP is requested sub-sequent times, only  _jspService() method is called.\
 - when hte server is stopped ot the application is undeployed, web container invoke
 jspDestroy() method.

1.Directived: are denoted using<%@.....%>
  they are 3 types.
   1. page
   2. include

   1. page : it used to confure JSP page.
          it provide several attributes
          attributes: 
              1.language:- default to- java and allow only value:"java"
                           used to specify Scripting language of the page.
              2. session:- used to specify whether the page participates in 
                           session or not.
                           it default to "true" and it means that the page participates
                           in session and predefined object: sesssion is available.
              3.isThreadSafe:- used to specify about thread safety of the page.
                               it default to "true" and it means that the page can be accessed
                               by multiple threads simultaneously.
              4.errorPage:- used to specify the name of the JSPpage.
                            this is the page to which control is diverted if the current jSP
                            page contains a java code which files an exception. 
              5.isErrorPage:- it default to "false" which indicates that the pages is not an 
                              error page and therfore the predefined object: exception is not 
                              available.
              6.import:-used to import API's from packages other than java.lang.
                                       

     2. include:- it is used  a resource like html,JSP or even a text file into a page.
             it provide a single attribute:file that specifies file name.

     3. taglib:- it is used during the development of custom tags i.e. user defined tags.

Implicit Object: there are several objects provide by web containerfor JSPs and therefore
these objects are referred as Implicit objects.

All these object are referred using predefined times and they are case-sensitive.

1.request
2.response
3.out
4.config
5.application
6.session
7.page
8.pageContext
9.exception

1.request:it is of type jakarta.servlet.http.HttpServletRequest and can be used 
          to fetch request specific parameters.

2.response: it is of type jakarta.servlet.http.HttpServletResponse and can be used
            to handle response specific functionalities.

3.out: it is of type jakarta.servlet.jsp.JspWriter and used to send response back to client.

4.config:it is of type jakarta.servlet.ServletConfig and it holds configuration specific
         information about the servlet that is generated by web container for the JSP.

5.application:it is of type jakarta.servlet.ServletContext and it used to hold application
             specific information.

6.session: it is of type jakarta.servlet.http.HttpSession and it used to handle 
           session level information.
7.page: it is of type java.lang.Object and it refer to ab Object of servlet specific
        class generated by web container for JSP.

8.pageContext :it is of type jakarta.servlet.jsp.PageContext and it used as single 
               object through which other objects can be obtained.
               it is espacially uesd while working with custom page.
9.exception: it is of type java.lang.Throwable and used to handle exception specific
             information.
             it is available only when [isErrorPage="true"] setting is used for page 
              directive.

                              As soon as it leaves the page, bean gets destroy.

              3.session: Bean is available as long as Session is present.
                         as soon as session is terminated, bean get destroy.
              4.application: Bean is available as long as Application is running.              
                              as soon as Application is stop, bean get destroy.

Working with <jsp:setProperty>:
                     it is standard action used to values to the properties of the bean
                     in order to assign the value, it provides serval pattern.

                     eg: property="*" used to assign values to all the properties
                                      this pattern work based upon one condition;
                                     note:- property names must match with request parameter name.

once the match is found, web container tries to search for setter method as per java naming convention
in the bean class and invokes them once they are found.
        there are futher pattern available for setting the properties.
            1.property="<<Prop-Name>>":   it used to set a value for an individual property.
                                          Like firest pattern, this pattern also work upon the same condition
                                                 property names must match with request parameter name.
            2.property="<<Prop-Name>>" param="<<Param-Name>>"
                                this pattern is used when property names do not match with request
                                parameter names.
                                eg: property="age" param="txt_age"
            3.property= "<<Prop-Name>>" value="<<value>>"
                               this pattern is used to assign a value directly to the Property.
                               it can be either a hard-coded value or derived from some expression.
                               eg:  property="age" value="30"
                                    <%
                                       int myAge=20;
                                      %>
                                      property= "age" value="<%=myAge %>"                   

Working with <jsp:getProperty>: web container invoke getter methods.
note:     both are invoke by web container                            

Other Actions:
    there are several other Standard actions provide by JSP
    1. <jsp:forward>
    2. <jsp:include>
    3. <jsp:param>


    1. <jsp:forward>: used to forword the request to next resource.
                     eg: <jsp:forword page= "next.jsp"/>
                     the Target resource generate the response back to client.

     2. <jsp:include>: used to include the resource in the current JSP page.
                            <jsp:include page= "next.page"/>
                       in this case the response of target resource is include in current JSP 
                       page and the current page generate the resource back to the client.
  <%@ include file= "background.html" %>      VS         <jsp:include>

  the include directive include the resource at tanslation time where whereas
  <jsp:include> includes the resource at request time.
   tanslation time: when jsp convert to servlet.

therefore , in general, html page are include using include directive whereas JSPs are included
 using include action.


                    INCLUDE IN JSP (Side-by-Side Comparison)
                   ----------------------------------------

   =====================================================================================
        INCLUDE DIRECTIVE                          |        <jsp:include> ACTION
        <%@ include file="x.jsp" %>                 |        <jsp:include page="x.jsp" />
   =====================================================================================

        Translation Time Include                    |        Request Time Include
   -------------------------------------------       |   -------------------------------------------
   • Included when JSP is converted to servlet.      |   • Included every time the request is made.
   • Both JSP files become ONE servlet.              |   • Files remain separate servlets.
   • Static include.                                 |   • Dynamic include.
   • Faster execution (done once).                   |   • Evaluates page on every request.
   -------------------------------------------       |   -------------------------------------------

                      SERVLET LIFE CYCLE                          JSP LIFE CYCLE
        ------------------------------------      ------------------------------------

        1. Load Class                             1. Load JSP
        2. Instantiate                            2. Translate JSP → Servlet (.java)
        3. init()                                 3. Compile Servlet (.class)
        4. service()                              4. Instantiate Generated Servlet
        5. destroy()                              5. jspInit()
                                                  6. _jspService()
                                                  7. jspDestroy()


    +----------------------------+         +-----------------------------+
    |        SERVLET             |         |            JSP              |
    +----------------------------+         +-----------------------------+
    | First Request →            |         | First Request →             |
    |  - Load Servlet            |         |  - Load JSP                 |
    |  - Instantiate             |         |  - Translate to Servlet     |
    |  - init()                  |         |  - Compile to Class         |
    |  - service()               |         |  - Instantiate Servlet      |
    |                            |         |  - jspInit()                |
    | Subsequent Requests →      |         | Subsequent Requests →        |
    |  - service() only          |         |  - _jspService() only       |
    |                            |         |                             |
    | On Shutdown → destroy()    |         | On Shutdown → jspDestroy()  |
    +----------------------------+         +-----------------------------+
